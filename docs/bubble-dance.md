# 泡泡跳舞機設計

想改數值，打開 `games/bubble-dance/dance-core.js` 改最上面的常數，再跑 `npm test`（約 1 分鐘）。

規則檔前端與伺服器共用，沒有 DOM 與 `Math.random`，同一組種子與舉手會重播出同樣結果。玩法致敬「跟著示範舉手」的懷舊小遊戲；角色全部用專案的泡泡人，名稱、美術、音效都是原創。

## 玩法

1. 單人：台上三個泡泡人，左邊老師、中間助教、右邊是你。連線：老師與助教站後排高台，這局所有玩家（含電腦）用各自外觀站前排，自己腳下有粉紅光圈、名字後加「（你）」。
2. 老師跟著節拍示範一組舉手動作，例如「右、左」。
3. 助教照做一遍。
4. 換你：照同樣順序、在同樣的拍子上舉手。
5. 全部做對就過關，下一回合動作更多、拍子更快。

## 操作

| 動作 | 手機 | 電腦 |
|---|---|---|
| 舉左手 | 下方左鍵 | ← 或滑鼠左鍵 |
| 舉右手 | 下方右鍵 | → 或滑鼠右鍵（頁面擋掉右鍵選單） |

畫面左邊那隻手是左手，像照鏡子。

## 回合

- 第 r 回合有 `min(r, 6)` 個動作（`MAX_LEN`）。動作左右由 `plan(seed, r)` 依種子產生，所有玩家同一組。
- BPM 從 80 開始，前 6 回合每回合加 4，之後每回合加 10，最高 180（`BPM0`、`BPM_STEP`、`BPM_FAST`、`BPM_MAX`）。
- 一回合的拍子：第 0 拍預備，老師第 1 到 n 拍，空 1 拍，助教 n+2 到 2n+1 拍，空 1 拍，玩家 2n+3 到 3n+2 拍，再空 3 拍收尾。
- 最多 30 回合（`MAX_ROUNDS`），到了還活著的人同名次。

## 判定

- 容許值：和拍點差 `min(0.2, 0.4 拍)` 秒內算準。80 BPM 是 0.2 秒，180 BPM 約 0.13 秒。
- 只有玩家照做那段算數：第一拍前到最後一拍後各一個容許值。老師與助教示範時舉手不算。
- 下面任一種就淘汰，台上的你變灰、垂頭，名字旁標「淘汰」；畫面上方顯示「觀戰中」，看到這局結束：
  - 舉錯手。
  - 多舉：不在任何拍點的容許值內，或同一拍舉兩次。
  - 少舉：拍點過了容許值還沒舉。伺服器多等 0.5 秒（`LATE`）才判，讓晚到的封包還能算。

## 名次

1. 中途離開的人排最後，帶 `out: true`，沒有積分。
2. 其他人比過關回合數（`score`）。
3. 同一回合淘汰的，比當回合舉對幾個（`ok`）。
4. 還一樣就同名次。積分 5、3、2、1。

結束條件：

- 連線：回合結束時只剩 1 人以下存活，或沒有真人存活。
- 單人：淘汰的那回合結束。分數是過關回合數。
- 真人全部斷線離開：立刻結束。

## 電腦

- 只在連線補空位，固定 `normal`。單人沒有電腦。
- `BOT_LEVELS` 寫「最早失誤回合」與「往後幾回合內隨機」：`easy` 3 到 6、`normal` 6 到 10、`hard` 10 到 15。
- 失誤回合與失誤在第幾個動作都由種子與電腦編號決定，可重播。

## 音效

沒有背景音樂。頁面用 Web Audio 即時合成：

- 節拍提示：每拍一聲輕點，回合第一拍較高。右上「♩ 開／關」切換。
- 舉手「啾」：左手音高低、右手高。老師與助教示範時也會啾，其他玩家舉手是較輕的啾。
- 淘汰：一聲悶響。
- 過關：兩聲上行的小提示音。

## 連線

- 房間 `DanceRoom`，路徑 `/dance/ws`，沿用 `GameRoom` 的大廳、倒數、斷線寬限與掛機踢除。
- 客戶端只送 `{t:'hand', side, at}`：`side` 是 `'L'` 或 `'R'`，`at` 是舉手那一刻換算成伺服器時鐘的毫秒（`net-sync.js` 的 `createClock`）。
- 伺服器照實際經過的時間推進（`stepDt`）。`at` 晚於現在當作現在，早於 0.5 秒前丟掉。
- 客戶端用同一份規則檔在本機判自己的舉手，淘汰立刻出現；名次以伺服器為準。
- 每格快照帶每人最近一次舉手 `h: [side, 遊戲秒數]`（每 50 毫秒一格）。真人每次舉手都記，舉錯也記；電腦在照做拍點舉對的手，失誤那拍不舉。客戶端看到 `h` 的時間變了，就讓台上那人舉手。
- 中途離開的人名字旁標「離開」，一樣變灰。

## 觀戰

1. 大廳畫面在對局進行中出現「👀 觀戰這局」，按下去看老師示範、所有玩家舉手、存活數與回合數，不能按鍵。
2. 開局後才連上、房間滿或沒加入的人，都留在大廳畫面，可以按觀戰。
3. 觀戰者不在 `lobby` 名單裡，不佔名額，不影響開局人數與結算。伺服器沿用 `GameRoom`：沒有座位的連線收到 `start` 時 `me` 是 `null`，照樣收快照，送來的 `hand` 不算。
4. 結束後觀戰者也看到結算，按「加入下一局」排進下一局。沒按的話，下一局開始時自動繼續觀戰。
- 斷線超過 10 秒判離開；斷線前已經淘汰的人保留名次。
- 紀錄榜還沒做，`recordStats` 回傳 `null`。

下一步：開 `/dance/?mode=solo` 跳 3 回合，確認老師、助教、你的節拍對得上（約 2 分鐘）。
